# Security policy

WAVault handles people's private contacts and messages, so security reports are taken seriously.

## Supported versions

Only the [latest release](https://github.com/md8-habibullah/wavault-whatsapp-web-backup/releases/latest) receives
fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through
[GitHub's private vulnerability reporting](https://github.com/md8-habibullah/wavault-whatsapp-web-backup/security/advisories/new)
or by email to [hello@habibullah.dev](mailto:hello@habibullah.dev).

Include what is affected, how to reproduce it, and the impact you expect. You will get an answer within 7 days.
Once a fix is released you will be credited, unless you prefer not to be.

## Scope

In scope: anything that could expose a user's WhatsApp data outside their own browser, script injection through
exported files (CSV, HTML, vCard, chat viewer), or the extension running on sites other than `web.whatsapp.com`.

Out of scope: problems in WhatsApp itself; report those to [Meta's bug bounty program](https://bugbounty.meta.com/).
