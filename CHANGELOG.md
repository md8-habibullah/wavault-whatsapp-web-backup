# Changelog

All notable changes to WAVault are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-19

First public release.

### Added

- **Contacts:** one merged list from the address book, chats and groups (duplicate phone and LID records merged);
  15 one-click lists; Any/Yes/No filters; group and WhatsApp Business label filters; search by name in any language,
  number in any format, @username, label or group; export everything or selected rows; 20 selectable columns.
- **Groups:** group list with members, admins, your role, created date and last activity; member lists with roles;
  export one sheet per group in Excel, or one row per person.
- **Chat backup:** full available history loaded page by page, with photos, videos, voice notes, documents and
  stickers decrypted; HTML viewer, Text (WhatsApp export layout), JSON and CSV; ZIP with a folder per chat and an
  index page; period and message limits; progress, stop, and an honest summary (partial history, expired media).
- **Status downloader:** all current updates by contact; save one, or a ZIP with gallery page and manifest.
- **Formats:** CSV, Excel (.xlsx), JSON, vCard 3.0 and 4.0, Google Contacts CSV, Outlook CSV, numbers list,
  HTML table, PDF.
- Light and dark themes (following WhatsApp), narrow-window layout, keyboard support.
- Builds for Chrome, Edge, Brave, Opera, Vivaldi, Firefox 140+ and Safari.
